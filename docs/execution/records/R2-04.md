## Implementation decision

- Intended observable result; non-goals:
  - Observable result: Real signatures for inherited/generic/overloaded members, traits, and Groovy extension modules match resolved declarations with provenance. Absence of library returns empty rather than invented API list. Grammar/snippets/protocol constants preserved.
  - Non-goals: Grails conventions / dynamic GORM finders capability adapters (R2-05).
- Files/owners to change:
  - `DeclarationProvenance.groovy`: Added typed immutable model for declaration provenance (sourceSetName, artifactCoordinates, declaringClass, signature, originKind, sourceAttachment).
  - `ResolvedDeclaration.groovy`: Added typed model for resolved declarations (name, kind, returnType, parameterTypes, genericTypes, isStatic, provenance).
  - `DeclarationDiscoveryService.groovy`: Engine for resolving declarations and Groovy extension module methods from ClassNode hierarchy and ClassLoader with provenance; returns empty for missing modules.
  - `SourceSetCompilationState.groovy`: Invoke syntax recovery in `catch (CompilationFailedException)` and ensure recovered AST is preserved when recompilation succeeds.
  - `DiscoveryService.groovy`: Integrated `DeclarationDiscoveryService` for member and extension method resolution; removed hardcoded fallback method lists.
  - `KeywordStrategy.groovy`: Delegated to shared authoritative `GrailsUtils.GROOVY_KEYWORDS`.
  - `GrailsUtils.groovy`: Defined authoritative `GROOVY_KEYWORDS` constant.
  - `GrailsInjectedStrategy.groovy`: Fixed unsafe AST node cast to `ClassNode`.
  - `GrailsHelperIntegration.groovy`: Added `allowFallback` parameter to support strict no-fallback resolution for missing classes while maintaining legacy compatibility for existing tests until R2-05.
  - `DeclarationDiscoverySpec.groovy`: Comprehensive Spock suite covering R2-04/1, R2-04/2, and R2-04/3.
- Input revision, candidate state, commit/publication and cancellation behavior:
  - Scoped to project RequestContext classloader, immutable declaration facts with provenance.
- Cache/resource impact, limits and invalidation:
  - Invalidate caches when project dependencies refresh.
- Alternatives considered and evidence for the smallest sufficient change:
  - Dynamic execution rejected per INV-DISC-003 and spec. Bytecode/classloader reflection and AST resolution used.
