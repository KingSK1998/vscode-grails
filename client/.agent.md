## Project Overview

This is a VS Code extension that provides comprehensive support for Grails and Groovy development. The extension integrates with the VS Code Gradle extension and provides language server capabilities, project exploration, code snippets, and development tools specifically tailored for Grails applications.

### Key Technologies
- **Language**: TypeScript
- **Framework**: VS Code Extension API
- **Target Languages**: Groovy, GSP (Groovy Server Pages)
- **Build Tool**: Gradle (via VS Code Gradle extension)
- **Language Server**: Custom Grails Language Server Protocol implementation

## Project Structure

### Core Directories
- `src/` - Main TypeScript source code
- `resources/` - Language configurations, grammars, snippets, and icons
- `out/` - Compiled JavaScript output (generated)
- `media/` - Extension icons and assets

### Important Files
- `package.json` - Extension manifest with commands, configurations, and dependencies
- `tsconfig.json` - TypeScript compilation settings
- `eslint.config.mjs` - ESLint configuration for code quality
- `src/extension.ts` - Main extension entry point and activation logic

## Architecture Overview

### Main Components

#### Extension Entry Point (`src/extension.ts`)
- Validates Gradle project structure (requires `build.gradle`)
- Initializes core services (StatusBar, ErrorService, GradleService)
- Starts Language Server Manager
- Registers commands and project explorer
- Handles extension lifecycle (activate/deactivate)

#### Core Services (`src/services/`)
- **GradleService**: Integrates with VS Code Gradle extension API
- **StatusBarService**: Manages extension status display
- **ErrorService**: Centralized error handling and reporting

#### Language Client (`src/languageClient/`)
- **LanguageServerManager**: Manages Grails Language Server lifecycle
- **clientOptions.ts**: LSP client configuration
- **serverOptions.ts**: LSP server startup configuration

#### Commands (`src/commands/`)
- **GrailsCommands**: Implements Grails-specific commands (run, test, clean, etc.)
- Artifact creation wizard (Controller, Domain, Service, etc.)
- Workspace setup automation

#### Project Explorer (`src/projectInfo/`)
- **GrailsExplorer**: Tree view provider for Grails project structure
- Displays Controllers, Services, and Domains in organized view

- Auto-closing pairs and bracket matching
- Comment toggling support

### Project Integration
- Requires VS Code Gradle extension (`vscjava.vscode-gradle`)
- Automatic project detection (looks for `grails-app` directory)

- Project explorer with artifact organization

## Configuration Settings

### Grails Settings
- `grails.path` - Path to Grails installation
- `grails.javaHome` - Java installation path for language server
- `grails.server.*` - Development server configuration

### Language Server Settings
- `grailsLsp.completionDetail` - Completion detail level (BASIC/STANDARD/ADVANCED)
- `grailsLsp.maxCompletionItems` - Maximum completion items (default: 100)
- `grailsLsp.includeSnippets` - Include code snippets in completion results
- `grailsLsp.enableGrailsMagic` - Enable Grails-specific features
- `grailsLsp.codeLensMode` - CodeLens configuration (BASIC/ADVANCED)
- `grailsLsp.compilerPhase` - Groovy compiler phase to use (default: 2)
- `grailsLsp.shouldRecompileOnChange` - Recompile project when configuration changes

## Troubleshooting

### Common Issues

## Language Server Integration

### Server Options
- **Development Mode**: Connects to remote server on configurable port (default: 5007)
- **Production Mode**: Uses local JAR file (`server/grails-language-server-1.0-all.jar`)
- **Debug Support**: Java debug agent configuration available

### Client Configuration
- Document selectors for Groovy and GSP files
- File system watchers for `**/*.{groovy,gsp}` patterns
- URI converters for proper file path handling
- Initialization options include Java home configuration

## Snippets and Language Support

### Groovy Snippets
- Controller, Service, Domain class templates
- Test specifications (unit and integration)
- Common patterns (actions, methods, properties, constraints)
- URL mappings

### GSP Snippets
- Layout templates with meta layout support
- Form elements and Grails tags (g:form, g:textField, etc.)
- Control structures (g:if/g:else, g:each loops)
- Expression syntax (${...}) and scriptlets (<% ... %>)
- Comments (<%-- ... --%>) and rendering templates
- Internationalization support (g:message)

### Language Configurations
- **Groovy**: Supports multi-line strings, GStrings, closures, and Groovy-specific syntax
- **GSP**: HTML-like syntax with Grails tag support, scriptlet blocks, and expression evaluation
